# 0003. Programmatic SVG for initial art

- **Status:** Accepted
- **Date:** 2026-10-23

## Context

The isometric office map (spec §4.2) needs desks, chairs, walls, doors,
plants and tables. Commissioning artwork up front would block the map work,
and assets need clear redistribution rights (spec §13.2).

## Decision

Draw the initial art in code as **programmatic SVG**: geometric isometric
primitives generated by `packages/isometric-map`. Assets are referenced
through an asset manifest so a designer can replace them later.

## Consequences

- The map is unblocked from day one, and every asset is original, so there
  is no licence question for the initial art.
- Shapes are simple. A visual polish pass (designer or illustration work) is
  expected before the pilot.
- The manifest boundary must be kept: components refer to asset IDs, never
  to inline SVG, so art can be swapped without code changes.
